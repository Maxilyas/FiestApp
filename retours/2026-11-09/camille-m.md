# Retour de Camille — 27 ans, téléphone Android (412 × 915)

## En une phrase
Je n'ai jamais pu entrer : la soirée s'est jouée et s'est terminée pendant que j'attendais, dans la cuisine, un mot sur la télé que je ne pouvais pas voir. Je n'ai rien joué.

## Mon parcours
- J'ai allumé mon téléphone, puis lancé `attendre "Code" 540 --tele`. Trois attentes de 540 s ont rendu « Au bout de 540,0 s, « Code » n'est pas apparu ». Une quatrième était en cours quand on m'a dit que la soirée était close. Soit au moins 27 minutes d'attente, sans aucune entrée, aucune capture, aucun écran de jeu vu.
- Les attentes n'ont rien rendu d'autre que cet échec. Je n'ai pas lu la télé, comme demandé.
- Pendant tout ce temps, je n'ai rien entendu de la salle : la voix de Nadia ne m'est parvenue qu'à mon premier geste suivant, `ouvrir /`. D'un coup, tout le déroulé m'est tombé dessus : Nadia annonçait « L'écran est allumé, scannez le QR ! Le code du salon : 711 503 », puis redonnait le code deux fois, avec « ouvrez localhost:45887/711503 ou tapez le code 711 503 dans « Rejoindre une soirée » ». Elle a lancé le quiz après dix minutes d'attente, noté « Camille » parmi les bonnes réponses (l'autre Camille, camille-d, était donc entrée), enchaîné un second quiz « Spécial Sam », puis dit « la soirée est finie ».
- À ce moment j'ai ouvert l'accueil `/` et lu l'écran (deux gestes, comme demandé). Pas de capture d'écran faite à ce moment-là.

## Pourquoi je ne suis jamais entrée
- **Ce qui vient de la consigne d'attente qu'on m'a donnée** : on m'a fait guetter le mot « Code » sur la télé. Or l'écran commun s'est allumé et Nadia a annoncé le code à voix haute, mais le mot que je guettais n'est jamais apparu sous cette forme (soit la télé affiche autre chose, soit elle n'a jamais dit « Code » tel quel). Mon attente a donc échoué trois fois de suite alors que la soirée était déjà ouverte. C'est un défaut de la consigne du jour, pas de l'application : je ne peux pas en conclure que la télé ne montre pas de code.
- **Ce qui vient de la façon dont les gestes sont rendus** : la salle ne m'est rendue qu'à mon geste suivant. Les attentes qui échouent ne rendent pas ce que dit Nadia ; je n'ai donc rien su pendant 27 minutes. Dans la vraie vie j'aurais reçu les messages dans le groupe. C'est une limite du pilote, pas de l'appli. Je n'ai pas utilisé `dire` pour demander de l'aide, alors que la consigne le prévoyait si je ne trouvais pas comment entrer : c'était mon erreur de ne pas l'avoir fait plus tôt.
- **Ce qui viendrait de l'application** (à vérifier, je n'ai pas essayé) : l'accueil ne m'a rien dit sur l'adresse ou le code.

## Ce que l'accueil propose à quelqu'un qui sait seulement « c'est chez Nadia »
Sur `/`, je vois : le titre « FiestApp · le quiz de soirée », les boutons « Jouer sans compte », « Me connecter », « Créer un profil », « Installer l'application », et un paragraphe sur le profil (« Un profil garde ton niveau, tes prix et tes avatars… Jouer n'en demande aucun »).
- Aucun champ pour taper un code, aucun lien « chez Nadia », aucune liste de soirées en cours à cet écran.
- Nadia parle d'un « Rejoindre une soirée » où taper le code : je ne le vois pas sur l'accueil. Il est peut-être derrière « Jouer sans compte » — je n'ai pas touché ce bouton, donc je ne peux pas le dire.
- Avec seulement « c'est chez Nadia », je ne sais pas quoi faire d'après cet écran : il faudrait l'adresse ou le code, que seule la télé ou Nadia donne.

## Ce qui m'a plu
- L'accueil est sobre et lisible, avec peu de boutons.
- Le message sur le profil dit clairement que jouer sans compte est possible.

## Ce qui m'a gêné
- **Où** : accueil `/`, pour quelqu'un qui n'a pas le QR. **Attendu** : un moyen visible de rejoindre une soirée (champ code, ou « Rejoindre »). **Constaté** : rien de tel au premier niveau ; seulement « Jouer sans compte ». **Gravité** : gênant, à confirmer en touchant « Jouer sans compte ». **Captures** : aucune.
- **Où** : toute la soirée. **Constaté** : je n'ai pu entrer à aucun moment. **Gravité** : bloquant pour moi, mais causé principalement par la consigne d'attente (« Code »), pas prouvé comme défaut de l'appli.

## Bugs constatés
- Aucun constaté sur l'appli : je n'ai pas joué. Je n'ai pas lancé `console`.
- À titre de note pour la tablée (hors personnage) : d'après ce que Nadia et d'autres ont dit, des convives ont signalé que la question reposée des poumons n'arrivait pas sur leurs téléphones, que le choix d'équipe (« Changer ») n'apparaissait pas après le podium, et que Nadia ne pouvait pas ranger quelqu'un dans une équipe. Je ne l'ai pas vécu : c'est entendu, pas constaté.

## Mes idées
- Sur l'accueil, un « Rejoindre une soirée » visible avec un champ pour le code, pour ceux qui n'ont pas le QR.
- Que le message envoyé aux invités contienne le code ou l'adresse, pas seulement « c'est chez Nadia ».
- (Pour la tablée) donner une consigne d'attente qui corresponde à ce que la télé affiche vraiment, et faire dire aux attentes qui échouent ce qui s'est dit dans la salle.
